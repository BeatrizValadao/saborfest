Gestão de reservas e camarotes

Gestão Manual

Como marcar camarotes esgotados

1️⃣ Aceda ao seu repositório GitHub do projeto.

2️⃣ Abra o ficheiro index.html.

3️⃣ Localize o bloco do camarote esgotado (por exemplo, Camarote 3).

4️⃣ Comente ou apague o bloco HTML correspondente:

<!-- <div class="ticket"> ... </div> -->

5️⃣ Faça commit e o site atualizará automaticamente na Vercel.

💡 Pode também remover a opção no ficheiro payment.html para impedir reservas.

Validação de pagamentos

Todos os comprovativos devem ser enviados para:

Email: sabordealvercafest@gmail.com

Após confirmação do pagamento, gere manualmente o QR Code e envie para o cliente.

Gerar QR Codes

Pode usar sites gratuitos como:

  • qr-code-generator.com
  • the-qrcode-generator.com

➡️ Use um padrão simples: SABORFEST-[NOME]-[TIPO]-[DATA]

Exemplo: SABORFEST-JOAO-PEDRO-CAMAROTE1

Check-in no evento

Na entrada, utilize a página checkin.html para validar QR Codes dos bilhetes.

✅ Se começar com SABORFEST-, será aceite.
