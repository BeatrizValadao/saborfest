Como funciona

Os códigos válidos começam com SABORFEST-.

Exemplo: SABORFEST-JOAO-PEDRO-CAMAROTE1

Se o código for válido, o sistema mostrará “✅ Bilhete válido! Entrada autorizada.”

Se não for válido, mostrará “❌ Código inválido!”.
